# AI Bookmark Manager

一款 Chrome MV3 书签整理扩展。继续使用 Chrome 原生收藏按钮；配置 OpenAI 兼容 API 后，扩展会对新增书签做分类，优先复用已有文件夹，并在低置信度或需要新目录时等待用户确认。

## 当前版本范围

此仓库实现 P0 与 P1：后台新增书签监听、文件夹树读取/验证/创建/移动、规则与缓存预分类、OpenAI 兼容模型、持久化队列、导入抑制、Review 通知与确认、设置、Popup、操作日志和最近自动移动撤销；P1 提供显式历史书签扫描、强制预览、逐条或批量批准、进度恢复和历史批量撤销。

摘要、标签、网页正文抓取、语义搜索、知识库问答、多 Provider、跨设备元数据同步等 P2 功能暂未实现。

## 环境要求

- Node.js 20 或更新版本
- pnpm
- Chrome 134 或更新版本

安装依赖并启动 Chrome 开发构建：

```bash
pnpm install
pnpm dev
```

验证生产版本：

```bash
pnpm typecheck
pnpm test --run
pnpm build
```

生产构建位于 `.output/chrome-mv3/`。在 Chrome 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择该目录。开发模式下 WXT 会输出供 Chrome 加载的开发扩展目录。

## 配置 AI

1. 点击扩展图标，再进入“设置”。
2. 填写 OpenAI 兼容 API 地址、模型名称和 API Key。
3. 点击“授权并测试 AI”。Chrome 会提示授予该 API 来源的可选网络权限；只会请求配置的来源，不申请访问所有网页。
4. 测试通过后，扩展开始处理之后新增的书签。没有 API Key 时，新书签保持原位并进入等待配置状态；配置完成后只恢复这些新书签。

支持 `https://` 地址；只有 `localhost`、`127.0.0.1` 和 `[::1]` 回环地址允许使用 HTTP。地址通常填写到 API 版本根路径，例如 `https://api.openai.com/v1`，不需要附加 `/chat/completions`。

API Key 存储在 Chrome 扩展本地存储中。这不是高安全级别的密钥管理方案。请使用可撤销、低额度的密钥，并避免在共享设备上保存；密钥不会写入源码、操作日志或通知。

## 整理策略

- 默认只自动整理直接保存在 Chrome 书签栏、其他书签或移动设备书签根目录中的新增书签。保存在用户自建文件夹内的书签默认保留原位；设置中的“强制整理”可以覆盖。
- Chrome Bookmarks API 不提供原生收藏弹窗中是否主动选择了某个内置目录的信息，所以无法单独识别用户明确选择了内置根目录；本版本按上述根目录规则处理。
- API Key 配置后，先查本地分类缓存和确定性标题/域名规则。只有规则不能高置信度匹配现有目录时才请求模型，降低调用成本。
- 置信度达到设置阈值且处于自动模式时，才自动移动到现有文件夹；确认模式中的移动、新目录建议和低置信度建议都会进入 Review 页面。新建文件夹始终需要用户确认。
- 每次自动移动都会记录原始和目标文件夹，可在 Popup 撤销最近一次自动归档。
- Popup 的“历史书签整理”会枚举已有 HTTP(S) 书签。历史扫描始终只生成预览，不会自动移动；Review 页面支持逐条处理或“批准当前全部有效建议”。默认只扫描内置书签根目录的直接子书签；开启“强制整理”后才包含自建文件夹中的后代书签。托管目录和非 HTTP(S) 项目始终跳过。
- 历史批量移动会保留可撤销记录。撤销前逐项检查书签仍位于扫描目标目录；已被用户移动或删除的项目会跳过，不覆盖当前状态。
- AI 服务失败、超时、权限不足、返回无效结构或推荐了无效文件夹 ID 时，书签保留原位并显示原因。暂不提供无 API Key 的纯本地自动分类模式。

## 权限与隐私

安装时申请的 Chrome 权限仅为 `bookmarks`、`storage`、`notifications` 和 `alarms`。没有静态网站 host 权限，也不读取网页正文、不访问浏览历史、不上传完整书签库、不使用登录服务或分析 SDK。运行时可选 host 权限只在用户点击设置中的授权操作后针对所填 API 来源请求。

模型输入仅包含当前新书签的标题、URL、域名、当前文件夹信息和已有文件夹 ID/名称/路径，不包含其他书签的标题/URL或网页正文。标题和 URL 按不可信文本送入提示；模型结果经过 Zod Schema 和当前书签树 ID 校验后才会进入决策层。

## 目录结构

```text
entrypoints/     MV3 后台、Popup、Settings、Review 页面
components/      React 页面与 shadcn 风格 Tailwind UI 组件
services/        Chrome 书签服务、分类、自动整理、通知
lib/             AI Provider、规则分类、提示、存储和工具
types/            共享业务类型与 runtime message 契约
tests/            Vitest 单元测试与 Chrome API Mock
```

所有扩展设置、任务、缓存、待确认建议和最近日志保存在本机 `chrome.storage.local`。禁用自动整理不会删除或移动任何书签。
