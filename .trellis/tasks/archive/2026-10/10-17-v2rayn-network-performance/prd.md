# 定位 v2rayN 下网速波动

## Goal

查明当前网络下应用直连和 v2rayN 代理速度波动的原因，区分本机 Wi-Fi、上游网络、系统代理路由和代理节点影响，并记录可复核证据。

## Background

- 主机运行 Manjaro Linux，当前连接 `Amber free WiFi`，频段 5 GHz，信号约 `-58 dBm`，接收协商速率 `156 Mbit/s`。
- v2rayN 和 Xray 正在运行，SOCKS 端口 `10808` 监听所有接口；经本机 Wi-Fi 地址访问该端口可成功完成 HTTPS 请求。
- GNOME 系统代理模式为 `none`，v2rayN `SysProxyType=0`，TUN 关闭；Chrome 主进程没有代理参数。因此未单独配置代理的应用默认直连。
- Wi-Fi 网关 `172.16.40.1` 以 0.5 秒间隔探测 16 次，0 丢包，平均 `4.7 ms`，最大 `9.0 ms`。
- 公网 DNS `223.5.5.5` 同样 0 丢包，但平均 RTT `211 ms`，最大 `511 ms`，表明路由器之后的网络路径延迟高且抖动明显。
- Cloudflare 下载对照中，直连多次约 `0.35–0.68 MB/s`，一次约 `0.047 MB/s` 并在 15 秒超时；经本机 SOCKS 多数约 `0.73–1.24 MB/s`，一次约 `0.16 MB/s`。样本显示代理通常较快，但代理和直连都存在波动。
- 首选 DNS `221.13.30.242` 首次查询约 `120 ms`，后续样本 `3–90 ms`；备用 `223.5.5.5` 样本约 `3–13 ms`。DNS 可增加新域名首次连接等待，但不能解释持续下载波动。
- v2rayN GUI 日志有 `net_http_connect_timedout` 和 `Connection reset by peer`，日志来自下载服务，不能单独证明 Xray 代理数据通道故障。
- 高频 ICMP 探测出现丢包，但降至每 0.5 秒一次后，本机网关和公网目标均无丢包；高频结果不作为链路丢包证据。
- UFW 服务处于 active；读取规则需要 sudo，当前未确认其他局域网设备能否连入 `10808`。该端口绑定所有接口，需按潜在局域网暴露处理。
- 用户提供的 Hysteria2 节点通过本机 sing-box 客户端认证并成功代理 HTTPS 请求，返回 HTTP 200；到服务器 ICMP 6 次无丢包，RTT `229–294 ms`，平均 `278 ms`。
- 同一 Cloudflare 1 MB 下载经 Hysteria2、客户端声明 `100/100 Mbps` 时为 `0.65–0.85 MB/s`；移除 `up_mbps/down_mbps` 后为 `0.39–0.85 MB/s`。小样本没有显示移除带宽声明后稳定改善，不能据此认定该设置是主因。
- 随后同目标复测 1 MB 下载：直连 `0.020–0.304 MB/s`（一轮 15 秒超时），当前活动 VLESS `0.377–0.561 MB/s`。结合 Hysteria2 `0.65–0.85 MB/s`，两种代理均快于直连样本，但绝对吞吐仍低。
- v2rayN 当前活动配置仍是 Xray/VLESS；本次 Hysteria2 测试单独运行，不能代表当前活动 VLESS 节点的性能。
- Hysteria2 生成配置启用 `tls.insecure`，且未带证书公钥 pin；连接性能测试不验证服务器证书身份。

## Requirements

- R1：用系统代理/TUN 状态和进程监听证明应用是否实际经过 v2rayN。
- R2：以同一目标的直连与 SOCKS 下载对照，区分代理路由和直连表现。
- R3：以网关和公网目标的分段 RTT 证据定位本机无线链路或上游网络问题。
- R4：说明证据能确认的结论与尚不能区分的因素，不把 GUI 下载日志误当作 Xray 数据通道日志。
- R5：整个排查保持只读，不修改代理、DNS、路由、Wi-Fi 或防火墙配置，不记录节点凭据。
- R6：对用户指定的 Hysteria2 节点做经认证的只读连接与吞吐验证，并与当前活动代理核心区分。

## Acceptance Criteria

- [x] 确认未显式配置代理的应用默认直连，且本机 Wi-Fi 到网关稳定。
- [x] 记录公网 RTT、DNS 和直连/SOCKS 吞吐对照，并说明其局限。
- [x] 给出根因判断：当前应用路由未启用系统代理/TUN；公共 Wi-Fi 直连和两个代理出口都低速，公网 RTT 高且波动。瓶颈位于本地网关之后的上游/远端路径；现有样本不能区分 Wi-Fi 上游拥塞与代理服务器出口质量。
- [x] 记录 `*:10808` 监听和 UFW 规则未核实的边界，不擅自修改配置。
- [x] 验证指定 Hysteria2 节点可连接，记录服务器 RTT 和吞吐；确认 `100/100 Mbps` 声明在短样本内未造成可复现的性能差异。
- [x] 确认该 Hysteria2 测试与 v2rayN 当前活动的 Xray/VLESS 节点不同，不混淆两者性能结论。

## Out of Scope

- 自动启用系统代理或 TUN，变更 DNS、路由、节点、Wi-Fi 或防火墙。
- 在其他网络或其他代理节点上做对照测试。
- 把 v2rayN GUI 下载服务日志解释为代理核心链路日志。
